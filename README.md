# PreetKnight Glass Launcher 📺

**PreetKnight Glass Launcher** (`com.preetknight.glasstv`) is a modern, ultra-fast, and minimalist launcher designed specifically for Android TV and Google TV devices (including Google TV Streamer 4K, Chromecast with Google TV, Nvidia Shield, and smart TVs).

Inspired by Apple tvOS design aesthetics and frosted glass ergonomics, it provides a clean, ad-free television experience.

---

## ✨ Features

- **Apple tvOS Solid Light Grey Theme**: A sleek, glare-reducing solid light slate grey settings backdrop (`#4E5260`) featuring frosted translucent glass tiles and smooth focus scale animations.
- **Custom 4K UHD Wallpaper**: Bundled with a default 4K custom wallpaper, plus instant integration with the [glasstv-wallpapers](https://github.com/preetknight/glasstv-wallpapers) catalog.
- **Preconfigured Defaults**:
  - Optimized 85% dock scale for seamless TV viewing distance.
  - Curated app dock ordering and quick access.
  - Scene mode set to Custom with Continue Watching tuned off for instant performance.
- **Real-Time App Update Feedback**: Native package installer hooks provide immediate visual alerts (`Updating <App>...` and `✓ <App> update complete!`) so you never have to guess when background app updates finish.
- **Lightweight & Ad-Free**: Zero bloat, zero tracking, and zero unwanted sponsored recommendations.

## 📥 Download & Install

Download the latest signed APK directly from the [Releases](https://github.com/preetknight/glasstv/releases) section:

👉 **[Download PreetKnight Glass Launcher APK](https://github.com/preetknight/glasstv/releases/latest)**

### Installation via ADB:
```bash
adb connect <your-tv-ip>:5555
adb install -r PreetKnight_Glass_Launcher.apk
```

### Installation via Downloader (TV):
Enter the direct release APK URL in the **Downloader** app on your Android TV device.
